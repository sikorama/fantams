# Libellés de triage

Les skills raisonnent sur cinq rôles canoniques. Cette table les fait
correspondre aux chaînes réellement employées dans ce dépôt — ici à l'identique,
faute d'un tracker préexistant dont il faudrait épouser le vocabulaire.

| Rôle dans les skills | Chaîne dans ce dépôt | Sens                                             |
| -------------------- | -------------------- | ------------------------------------------------ |
| `needs-triage`       | `needs-triage`       | Le mainteneur doit évaluer cette issue           |
| `needs-info`         | `needs-info`         | En attente d'un complément d'information         |
| `ready-for-agent`    | `ready-for-agent`    | Entièrement spécifiée, prête pour un agent seul  |
| `ready-for-human`    | `ready-for-human`    | Demande une implémentation humaine               |
| `wontfix`            | `wontfix`            | Ne sera pas traitée                              |

Quand un skill nomme un rôle, employer la chaîne correspondante de cette table.
Les chaînes restent en anglais : ce sont des identifiants, pas de la prose.
